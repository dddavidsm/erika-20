# Fotografías de destinos

Las fotografías de esta carpeta son imágenes reales de Wikimedia Commons, descargadas como miniaturas locales para que la web siga siendo estática y cargue rápido. Cada destino y cada lugar reconocido mantiene el enlace a su ficha original en `src/data/destinations.ts`.

Consulta siempre la ficha original antes de reutilizar estas imágenes fuera de este proyecto, ya que las licencias y atribuciones concretas pertenecen a cada autor.
